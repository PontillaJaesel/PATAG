# P.A.T.A.G. 
**Public Access to Truth, Alliances, and Governance**

---

## What is P.A.T.A.G.?

P.A.T.A.G. is a third-party, web-based transparency platform built to combat the spread of misinformation and encourage informed voting in the Philippines. By serving as a central, unbiased database, it provides citizens, academic researchers, and journalists with fact-checked political records, legislative progress tracking, and media integrity tools. 

It acts as a civic command center for evidence-backed governance updates, allowing users to search high-ranking executive and legislative records and monitor branch signals.

---

## Core Features

* **Fact-Checked Official Profiles:** An unbiased data hub detailing an official's full credentials, career history, and fact-based controversies. This includes a Campaign Promise Tracker to audit pre-election commitments against actual deliverables.
* **Legislative Progress Tracker:** A visual, timeline-based tracker to monitor a bill's journey from filing in the House or Senate to the President's signature, complete with direct authorship attribution.
* **Voter Analytics and Insights:** Regional endorsement heat maps and occupational analytics generated through a secure, identity-verified registration system that is exclusive to voters aged 17 and above.
* **Truth and Media Integrity Suite:** An embedded, fact-checked political newsfeed alongside deepfake and fake news detection tools to help the public verify the legitimacy of circulating media.
* **Transparency and Governance Watch:** High-level performance oversight for major government departments, such as the DOH, DepEd, and DPWH, and visualizers for shifting political alliances.

## Tech Stack

This project is built with a modern, high-performance web stack focusing on a seamless user interface and robust local data management:

| Component | Technology | Purpose |
| :--- | :--- | :--- |
| **Framework** | React with TanStack Start | Server-side rendering and routing. |
| **Routing** | TanStack Router | Highly dynamic, type-safe navigation. |
| **Database** | SQLite (via libSQL client) | Lightweight, rapid local data querying. |
| **Styling** | Tailwind CSS | Fully responsive, custom UI design utilizing a specialized color palette. |
| **Icons** | Lucide React | Crisp, scalable UI iconography. |
| **Environment**| Bun | Primary Javascript runtime and package manager. |
